# Circuit design reference

Original flat course, not a traced F1 layout. The design uses heavy braking, flowing linked bends, exit-critical corners and uninterrupted acceleration zones as a distinct rhythm rather than adding repeated kinks. The SVG shows actual sampled geometry and target speed.

Reference reading:
- Formula 1 COTA circuit guide: https://www.formula1.com/en/latest/article/circuit-guide-everything-you-need-to-know-about-circuit-of-the-americas.3OjhBbugiQRmN4FnlpBtBc
- McLaren Imola track guide: https://www.mclaren.com/racing/formula-1/2020/emilia-romagna-grand-prix/imola-track-guide/

Implemented length is 3033.654 m, with about 670 m and 550 m uninterrupted straights. 720 samples are equally spaced. Typical guided flying laps are approximately59 seconds in normal-control tests; player times vary. No DRS claim, elevation claim or official circuit licensing is implied.
